# 起動方法

## モデルのトレーニング

- 以下のコマンドをルートディレクトリ(`/`)で実行してください。
- 以下のコマンドを実行すると、`experiments/trained_models/pnn`にモデルが保存されます。

```
python -m src.methods.pnn.train
```

# モデルの推論

- 以下のコマンドをルートディレクトリ(`/`)で実行してください。
- 以下の例のように使用するモデル名をコマンドラインで指定してください。

```
python -m src.methods.pnn.inference pnn_model_20241019_111327.pth
```

# 結果

- PNN を用いて XOR 分類を行うことができました。
- PNN は 3 層構造のネットワークであり、かつ逆伝播を行わないため学習のコストが少ないモデルだということがわかりました。
